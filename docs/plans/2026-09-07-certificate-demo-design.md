# 本地证书提取与审核 Demo

用户已确认：结果按证书整理成表格，按证书类型配置必填字段，标出未识别、待核对和不适用字段，支持原图复核。当前授权实现简单 Demo。

采用本地 FastAPI、静态 HTML/CSS/JavaScript、SQLite 和单工作线程常驻 PaddleOCR。浏览器绑定 127.0.0.1，上传图片不发送外部服务。相较命令行 skill，网页更便于客户测试逐字段复核；相较完整生产系统，本次不加入通知、人员调配和账号系统。

实现步骤：
1. 字段提取与校验：电工作业证、HCIP 与未知类型；保留 OCR 原文、坐标、置信度和人工修正；测试日期语义和噪声处理。
2. 本地服务：真实 OCR 队列、图片导入、SQLite 持久化、模板规则、人工审核、CSV 导出；测试版本冲突和缺失字段拦截。
3. 审核界面：结果表、筛选、图片与字段对照、规则配置、导出；浏览器实测。
4. 用 9 张指定截图实际调用 OCR，验证人工修正、刷新留存、模板变更和导出，再留下可直接打开的演示。

业务边界：资料审核通过与证书当前有效是两个状态。不得把初领日期当作有效期开始；旧证复审信息语义不明时待核对。未知类型需人工选择。缺失字段不能自动填入参考答案。仅以真实 OCR 输出生成演示数据。

界面采用简洁的工业业务工作台：浅灰底、墨色文字、蓝绿色操作、橙色待处理和红色缺失标记。按证书一行展示，右侧对照查看原图与字段。
