如何测试这个 Demo
  1. 导入样例或上传图片，等待本地 OCR 完成识别。
  2. 在“字段规则”中设置每种证书必须填写的字段。
  3. 点击“核对”，对照原图补录缺失信息。原始识别值保留在字段下方。
  4. 对仅有年月、含义不明或低置信度的字段，核对后勾选“已核对”。
  5. 填写审核人，确认字段审核，再导出 Excel 或 CSV。
本 Demo 只做图片识别、字段整理和审核。期限提示依据日期计算；“已审核”表示字段已确认，不是证书真实性或上岗资格的认证结论。
