# 证书提取与审核 Demo

在本机运行的图片 OCR、字段表格和人工审核工作台。采用真实 PaddleOCR，不使用写死的识别答案，也不把上次测速结果当成新识别。

## 启动

页面顶部显示 OCR 模型状态，并提供“启动 OCR”和“关闭 OCR”。模型加载或识别任务未完成时不能关闭。关闭会卸载模型对象、清理可释放缓存，保留网页服务和证书数据；CUDA 运行时可能仍保留少量显存。上传或框选识别会自动启动模型，启动耗时可以悬停状态查看。

双击当前目录中的 `Start-Demo.cmd`，会启动服务并打开浏览器。默认使用 Conda 环境 `D:\Apps\miniconda3\envs\fapiao`、CPU 推理和项目内 `models\official_models` 权重。发票入口 `invoice_demo\Start-Invoice.cmd` 打开 <http://127.0.0.1:8765/invoices>；证书入口打开 <http://127.0.0.1:8765>。双击入口使用 Python，不需要改变 PowerShell 的脚本执行策略。

启动器默认将 PaddleX 缓存放在 `models\paddlex-cache`。如需更换 Python、模型目录或推理设备，可设置 `CERT_DEMO_PYTHON`、`CERT_OCR_MODEL_ROOT` 和 `CERT_OCR_DEVICE`；本机没有 NVIDIA GPU，默认设备为 CPU。

## 测试步骤

1. 点击“导入 9 张样例”，或批量上传 JPG、PNG、WEBP。每张不超过 15 MB；重复文件按哈希去重。
2. 观察模型加载与识别状态。图片和文字保存在 `data`，刷新页面不会丢失结果。
3. 点击“核对”，修改字段、查看原始 OCR 值和对应文字位置。点击“保存修正”后重新校验。
4. 对低置信度、仅有年月、复审语义不明等内容，核对后勾选“已对照原图核对该字段”。不合法日期仍会拦截。
5. 填写审核人，确认字段审核。缺失或待核对字段未处理时不能通过。
6. 修改“字段规则”中的必填项；同类现有记录重新校验，已审核记录需重新确认。
7. 按状态、证书类型或姓名筛选，导出当前结果为 Excel 或 CSV。Excel 中缺失字段标红。

## 数据含义

- 一张图片一条记录，此 Demo 按一张主要证书处理，不做多证书自动拆分。
- 未识别、待核对、不适用独立展示；未填日期不会默认有效。
- 已审核表示提取字段已人工确认，不代表真伪核验或岗位资质审批。
- 按当前业务口径，初领日期作为业务开始日期，默认必填。有效期限起始日另行保留，默认选填；到期提示仍取有效期结束。复审日期的历史记录与应复审截止日分别处理。
- 原始文字、框坐标、置信度、人工修正和操作历史分别保存。重新识别保留人工修正，同时取消原审核确认。
- 此版本支持本地图片审核、人员档案、站内预警任务及换证管理，没有账号体系、外部消息推送、官方证书核验或替补派工。
- 服务只监听 127.0.0.1；没有配置局域网访问。数据目录含个人证书信息。

## 文件

- `app.py`：本地接口、队列、OCR 和 SQLite。
- `extraction.py`：证书类型、字段规则、文字坐标解析及校验。
- `static/`：工作台前端。
- `data/demo.sqlite3`：原始 OCR、修正、审核及规则。
- `data/images/`：本地图片及识别方向对照图。

## 框选重识别（2026-09-08）

1. 打开一条记录，点击目标字段旁的“框选重识别”。
2. 在左侧图片上拖动选区，单行文字尽量只框字段值并留少量边距。有效期限可以框起止日期整行。
3. 点击“识别选区”。单行模式绕过文本检测，分别显示原色和灰度增强候选；多行模式列出区域检测到的文字行。
4. 核对候选文字后点击“填入待保存字段”，最后点击“保存修正”。区域候选未保存前不会改变台账。
5. 保存后显示“区域识别”来源，整图 OCR 原值不覆盖；手工再次修改则标为“人工修正”。

框选坐标对应识别方向的图像；切换原始方向会取消当前选区。低置信度与非法日期仍受校验，候选绑定记录版本。不要单凭最高置信度选结果，增强处理有时也会损失字符。

升级自动保留现有记录、人工修正和有效期限起始日。迁移前数据库备份位于 data/before-date-policy-v2.sqlite3。电工证原必填“有效期开始”迁移为“初领日期（业务开始日期）”，原审核确认取消，按新规则重新审核。

列表操作栏新增“删除”。确认后条目不再出现在列表、数量统计及导出中；原图和审核记录保留，可以通过回收站恢复。已审核和其他已结束识别的条目均可删除，排队及识别中的条目不可删除。接口校验记录版本，防止覆盖他人刚完成的修改。

## 审核体验更新

- 支持复选框勾选、全选当前筛选结果和批量删除（每批最多 500 条）。切换筛选后隐藏条目取消勾选；任何条目冲突都会阻止整批删除。
- “展示方式”可切换为按人员分组。已关联档案按人员编号区分，未关联证书仍按姓名展示，未知姓名单列；未关联同名记录不代表身份已合并。

- 新增独立“证书风险”列和风险筛选，有效期与复审风险同时显示。“字段已核对”仅表示人工字段审核。
- 审核页新增复审管理：上次复审、下次应复审、证明状态及依据。含义不明的原始复审信息不会自动归类；标记证明已核对时必须填写审核人及依据。Excel / CSV 同步增加五列。
- 缺失及待核对字段优先展示；“下一个待核对字段”定位问题项。“审核并下一张”在当前筛选队列中继续，审核不通过则停在原记录。

## 2026-09-16 人员、预警、换证及数据恢复

人员档案、预警任务、回收站、数据备份均为主内容区页面，通过左侧导航切换。URL 使用 `#people`、`#alerts`、`#trash`、`#backup`，支持刷新保留页面以及浏览器前进/后退；刷新不保留未提交的表单内容。证书原图核对和归属/换证操作仍使用弹窗。

1. 左侧“人员档案”新建人员，填写姓名、项目、岗位、安全员及在岗/可调配/离岗状态。人员编号由系统生成，同名允许分别建档。
2. 在证书行点击“归属 / 换证”，核对身份后选择人员并填写核对依据。旧记录不自动按姓名合并。
3. “预警任务”默认提前 10 天、5 天提醒，可配置 1–365 天内的最多 6 个阈值。有效期与复审独立建任务，缺失或不确定日期产生核实任务。同一证书、事项和截止日只生成一个任务，阶段变化会重新待处理。
4. 服务运行时每分钟扫描，打开任务页也会检查。电脑休眠或服务停止期间不执行；重启后按当前日期补查，不追发已错过的阶段。没有外部消息发送。
5. 任务支持责任人、待处理/处理中/已解决、处理依据和历史。手工关闭任务不会更改证书日期或移除列表风险。未关联人员的风险仍会进入任务中心，需要分配责任人。
6. 上传新证后关联同一人员，在旧证“归属 / 换证”中选择后续新证。要求同类、同作业项目/认证方向且到期日延长。审核通过且已生效的新证使旧证成为历史；删除新证、解除关联或审核失效后会重新检查旧证。新证后来到期时只提醒新证，不重新启用旧证。
7. 左侧“回收站”可多选恢复原图及全部修正记录，批次内任何版本冲突则整批不恢复。
8. 列表支持到期排序、当前/历史筛选、固定人员及操作列、导出所选 Excel。导出附人员编号、档案姓名、项目、岗位、安全员、当前/历史标记。
9. 签发机关解析改为标签和附近文字位置匹配，避免只接受政府机构关键词。对新识别/重新识别结果生效，既有人工修正仍优先保留。

### 备份与离线恢复

左侧“数据备份”下载 ZIP，包含数据库、所有被引用的证书图片（含回收站）及 SHA-256 清单。不包含 OCR 模型或 Python 环境；更换电脑时须另配运行环境。

恢复只写入全新目录，不覆盖正在使用的数据。示例（请替换备份路径和新目录）：

```powershell
& 'D:/python1/python.exe' -X utf8 -B cert_demo/restore_backup.py 'D:/backups/certificate-backup.zip' --target 'D:/backups/restored-certificate-data'
```

恢复工具校验 ZIP 路径、文件哈希、数据库及图片引用，并重写图片路径。检查恢复结果后，停止旧服务，设置 `CERT_DEMO_DATA` 指向新目录再启动；原目录始终保留。

本轮没有实现排班冲突检查、替补派工、服务端分页、多证图片自动拆分或多人权限管理。
