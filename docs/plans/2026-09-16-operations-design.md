# 人员与预警管理实施方案

用户已授权按上一轮建议实施。沿用本机 FastAPI / SQLite / PaddleOCR，增加独立业务模块，不迁移或重写原有 OCR 记录。

## 本轮交付
- 人员档案：独立编号、姓名、项目、岗位、在岗状态、安全员；手工关联证书，同名不自动合并。
- 预警任务：可配置提前天数，服务运行期间每分钟扫描；到期和复审分开，任务去重，处理记录及版本校验。关闭任务必须填写依据，不会消除证书风险。无外部消息发送。
- 换证链：关联同人、同类别/作业项目的新旧证；新证经过字段审核、日期延长且已生效后旧证进入历史。新证删除或审核失效时旧证重新进入风险扫描。
- 回收站：查看与批量恢复软删除记录；保留原图、修正和审核记录。
- 完整备份：数据库与被引用的图片，离线恢复工具进行校验和路径重写。
- 提取修正：签发机关依据标签与位置，避免机构关键词白名单漏掉培训中心。
- 列表：到期排序、历史状态筛选、所选导出和固定操作列。

## 验证
独立临时数据库测试人员归属、版本冲突、预警去重/升级/关闭、换证生效/回退、批量恢复原子性与备份完整性；保留现有 OCR 回归测试。浏览器只查看真实数据，操作测试使用独立测试环境。

## 边界
仍为单机演示版；关闭服务后不扫描，不发送通知。不把字段核对等同于官方核验或岗位准入。人员排班、替补调配、多证图片拆分、账户权限与服务端分页是后续工作。
