# 发票报销识别页面

用户要求在现有网页原型基础上新建发票报销系统，复用本地 PaddleOCR，保留证书应用。

- 独立路径 `/invoices`，同进程复用 GPU OCR 和单 worker 队列，存储在 `invoice_demo/data`。
- 两种业务台账为公司往来发票（图1到图2）和费用报销发票（图3到图4），购买和销售不拆分。上传前选择台账，核对时可调整，票种不决定台账。
- 公司往来按示例图2九列导出：日期、公司名称、开票日期、发票号码、不含税金额、税率、税额、金额、专票。日期与开票日期两列均取票面开票日期，公司名称默认销售方，提供导出选择购买/销售方。
- 报销表按图4十列：序号、报销人、名称、金额、税率、税额、总额、发票号码、开票日期、专票/普票。报销人保持空白。
- 原始票种和业务分类分开：增值税专票/普票、火车票、待确认；火车票按客户口径归专票，不据此断言税务资格，不猜税率。
- OCR 根据标题分类，根据二维坐标区分左侧购买方、右侧销售方；单列台账保留项目名称及费用类别。多明细保留子表，财务汇总每张发票一行，多个税率并列显示，避免重复计入票面总额。
- 独立详情页面核对，缺失/低置信度/金额勾稽异常标记，保留原始文本、位置与手工修正；长票号 Excel 作为文本。
- 支持批量图片上传、筛选、业务类型调整、批量软删除和回收站恢复、导出所选/当前范围、模型状态及启停。
- 支持图1、图3作为真实 OCR 测试发票；图2、图4仅作导出格式参考，不当发票上传。
- 文件哈希去重；发票号码相同但图片不同标记重复待核对，不自动合并。
- 最新修正：支持PDF逐页渲染OCR（最多20页、每页一票），PDF文字标题辅助自动区分专票普票。餐饮、住宿、旅客交通等费用项目优先费用报销，其余专票默认公司往来，其余普票默认费用报销。上传默认自动，详情允许人工调整。单页多票拆分、官方验真和财务系统对接另行扩展。
